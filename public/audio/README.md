# Audio assets

Coloca aquí los archivos de sonido opcionales en formato `.mp3`, `.ogg` o `.wav`.
El juego los busca con estos nombres (los sonidos sintetizados integrados sirven
como respaldo si todavía no se han añadido):

| Archivo | Uso |
| --- | --- |
| `ui-select.ogg` | Selección de destino o acción de interfaz |
| `mission-launch.ogg` | Inicio de una ruta espacial |
| `science-scan.ogg` | Escaneo o recolección científica |
| `mission-complete.ogg` | Transmisión y recompensa de campaña |
| `resource-warning.ogg` | Aviso de recurso crítico |

Los nombres y rutas son relativos a `public/audio/`; por ejemplo, `public/audio/ui-select.ogg` se sirve como `/audio/ui-select.ogg`. No se incluyen grabaciones para evitar distribuir audio sin licencia.
